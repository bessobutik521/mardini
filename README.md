# المارديني — للحوالات المالية

منصة عربية RTL مصممة للهاتف، باستخدام React وNode.js وSQLite. تحتوي على شراء وبيع USDT، وتصريف شام كاش دون عمولة، وتتبع الطلبات دون حساب، ولوحة إدارة محمية وتأكيد دفع يدوي.

## التشغيل المحلي

يتطلب Node.js 24 أو أحدث.

```powershell
npm.cmd install
npm.cmd run dev
```

الواجهة: `http://localhost:5173`، لوحة الإدارة: `http://localhost:5173/admin`، الخادم: المنفذ `3001`.

## إنشاء حساب الإدارة

لا توجد كلمة مرور افتراضية أو أسرار في الواجهة. لإنشاء حساب، عيّن القيم في بيئة الطرفية:

```powershell
$env:ADMIN_USERNAME = Read-Host 'اسم مدير المنصة'
$secret = Read-Host 'كلمة مرور لا تقل عن 12 حرفًا' -AsSecureString
$env:ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', $secret).Password
npm.cmd run admin:create
Remove-Item Env:ADMIN_PASSWORD
```

إعادة الأمر لنفس الاسم تحدث كلمة المرور وتلغي جلساته السابقة. سجل الدخول عبر `/admin`.

## إعداد المنصة قبل استقبال الطلبات

1. **الشبكات والعناوين:** أدخل عناوين إيداع USDT الحقيقية ثم فعّل الشبكات المطلوبة، وأدخل حسابي شام كاش للدولار والليرة. الشبكات الأولية غير مفعلة والعناوين فارغة عمدًا.
2. **العمولات:** راجع شرائح الأسعار الأولية التجريبية. الحد المشترك يُنسب للشريحة الأدنى (100 ضمن 2٪، و100.01 ضمن 1.5٪). يدعم النظام المبالغ الكسرية ويمنع تداخل الشرائح، ويرفض العمليات التي لا تغطيها شريحة مفعلة.
3. **أسعار الصرف:** عدّل السعر الأولي التجريبي 12,500 ليرة لكل دولار.
4. **الخدمات:** راجع الحدود والاتجاهات والعملات والملاحظات. الحدود مقوّمة بالدولار أو USDT؛ المبالغ بالليرة تُحوّل إلى قيمتها الدولارية للتحقق.
5. **الإعدادات:** أدخل بيانات الدعم والشعار الرسمي. صورة المحادثة لم تصل كملف للمجلد؛ العلامة الحالية رسم مؤقت مستوحى منها. ضع ملف الشعار في `public/logo.png` ثم أدخل `/logo.png` في رابط الشعار، أو استخدم رابط HTTPS. استبدل أيضًا أيقونات التطبيق بالشعار الرسمي عند توفر ملفه.

## نسخة الإنتاج

```powershell
npm.cmd run build
$env:NODE_ENV = 'production'
npm.cmd start
```

يشغّل الخادم الواجهة وواجهات API معًا على المنفذ `3001`. يجب تقديمه عبر HTTPS لتفعيل جلسات الإدارة الآمنة وميزات PWA. استخدم `PORT` لتغيير المنفذ و`DATA_DIR` لتحديد مجلد البيانات. عند وجود وكيل عكسي موثوق، عيّن `TRUST_PROXY` إلى عدد الوكلاء الصحيح.

للمعاينة المحلية للنسخة المبنية عبر HTTP، شغّل `npm.cmd start` دون تعيين `NODE_ENV=production`.

## البيانات والأمان

- قاعدة البيانات `data/mardini.sqlite`، والإثباتات `data/proofs/`. احفظ هذا المجلد في تخزين دائم مع نسخ احتياطية. استخدم نسخة احتياطية متسقة لـSQLite؛ لا تنسخ ملف القاعدة وحده أثناء وجود كتابة نشطة في WAL.
- العمولة والسعر وعنوان الإيداع واسم الخدمة وملاحظتها تُنسخ إلى الطلب وقت إنشائه، ولا تتغير بتعديل الإعدادات.
- رقم الطلب عشوائي طويل؛ هو وسيلة الوصول إلى تفاصيل الطلب دون تسجيل مستخدم، لذلك يُعامل كرابط خاص لا يُشارك علنًا.
- كلمات مرور الإدارة مشتقة باستخدام scrypt، والجلسات محدودة بثماني ساعات ومحفوظة في قاعدة البيانات كقيم تجزئة، والكوكيز HttpOnly وSameSite.
- التحقق النهائي والحسابات يجريان على الخادم. إثباتات الدفع لا تُعرض إلا للإدارة، والملاحظات الداخلية لا تعاد ضمن بيانات التتبع.
- التحويلات وتأكيد استلام الأموال يداران يدويًا، ولا يوجد اتصال بمحافظ أو مفاتيح خاصة.
- يدعم التطبيق التثبيت حيث يسمح المتصفح، مع manifest وأيقونات PNG وشاشة انقطاع اتصال. العمليات المالية تتطلب الإنترنت ولا تُخزن API أو الإثباتات في ذاكرة PWA المؤقتة.

## الفحص

```powershell
npm.cmd test
npm.cmd run build
npm.cmd start
# في طرفية أخرى؛ يعتمد الفحص المرئي على Microsoft Edge المثبت
npm.cmd run test:visual
npm.cmd run test:journey
```

فحوص العمليات تستخدم قاعدة بيانات منفصلة مؤقتة وتتحقق من حدود الشرائح، ثبات أسعار الطلبات، حماية الإدارة، إثبات الدفع، وعدم تسريب الملاحظات الداخلية. صور المقاسات المطلوبة تحفظ داخل `test-results/`.

فحص الرحلة يشغّل خادمًا مؤقتًا وقاعدة منفصلة، ويسجّل دخول الإدارة، ويضبط عناوين الاستقبال، وينشئ طلب USDT من واجهة الهاتف ويرسل إثباته، ثم يكمله يدويًا من الإدارة ويتتبعه من واجهة العميل. ملفات الخط العربي مستضافة محليًا ضمن المشروع ولا تعتمد على تحميل الخط من خدمة خارجية.
